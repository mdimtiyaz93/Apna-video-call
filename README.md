# Apna Video Call

A real-time video calling web application built using React, Node.js, Express.js, Socket.IO and MongoDB.

## Features

* User Registration & Login
* Video Calling
* Audio & Video Controls
* Real-time Chat
* Multiple Participants
* Guest Join
* Meeting History
* Responsive Design

## Tech Stack

* React.js
* Node.js
* Express.js
* Socket.IO
* MongoDB
* Material UI
* CSS

## Live Demo

https://apna-video-call-frontend-8pau.onrender.com/

## Run Locally

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
npm install
npm start
```

## Environment Variables

Create a `.env` file inside the `backend` folder:

```env
MONGO_URL=your_mongodb_connection_string
```
